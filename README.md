# AI Agent TikTok Video Konten

Seri edukasi animasi 2D flat motion graphic tentang **Cara Kerja Automasi AI Agent**.

- Format: 9:16 vertikal, target 1080×1920, 30 fps
- Durasi: 4 bagian × 30 detik = 2 menit
- Karakter: Ava, robot AI kecil dengan panel hologram
- Visual: navy, ungu, neon cyan dan magenta
- Audio: VO bahasa Indonesia, electronic upbeat, UI SFX
- Subtitle: burned-in, putih bold dengan outline gelap, maksimum 6–8 kata per layar
